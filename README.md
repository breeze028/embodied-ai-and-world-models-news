#### 1. 【动力学辨识】SUSS v0.2.0 验证晚层注意力缓存的因果作用

**来源与类型**　Anuar Zhambakin，独立研究者，论文修订与可复现实验。  
**公开时间**　2026-11-08 02:44:17，北京时间。  
**评分**　80/100。  
**关键词**　上下文适应 · 动力学辨识 · 预注册 · 注意力缓存。

**一句话。** 第二轮预注册检验发现，交换另一段历史的晚层键和值，可在三种受测配置中显著转移一步预测行为。先验变化试验显示，冻结模型的预测函数仍更接近使用训练先验的岭回归。

![SUSS 第二轮预注册结果表](paper-reading/news/2026-11-08/suss/images/page_017_fig_table_4_review_repair1.png)

- **干预与读出。** 在长训、深层、宽层三个配置中，交换网络后半部分的上下文 K/V，行为转移系数为 0.85–0.96，首层对照为 0.01–0.13。同维度下，快权重相对最佳残差读出的 $R^2$ 优势为 0.21–0.35。探索性 10 万参数模型的优势反向，约为 −0.07。
- **分布变化。** 将测试系统状态转移矩阵元素的先验标准差由 0.4 降至 0.1 后，查询雅可比到训练先验岭回归、新先验贝叶斯参考、普通最小二乘的均方距离约为 0.026、0.028、0.036。10 个训练种子的方向一致，两个先验对照的差距较小。全部 11 项经 Holm 校正后满足预注册判据。
- **与上一版的区别。** 11 月 7 日已报道最初的键值机制线索和控制尾部风险。本次纳入的是新公布的三配置确认与先验偏移试验。新增证据来自低维线性动力学预测，真实机器人与闭环稳定性仍待验证。

**工程含义。** 对用历史做适应的策略，可以把预测函数的雅可比、同维度读出和缓存干预拆开测，分别定位分布偏好、可读出信息和实际影响。后续还需用闭环扰动与失败率衡量是否能迁移到控制。
